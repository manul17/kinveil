# Design & Protocol Invariants

Architectural guarantees enforced across vault storage, systemd units, nftables rules, and protocol renderers.

## Encrypted Vault (`state.enc`)

- **Envelope (`KVEL\x01`):** 45-byte binary header (magic `KVEL`, format `1`, 16-byte salt, Argon2id `m=131072` KiB / `t=3` / `p=1`, 12-byte nonce) authenticated as AES-256-GCM AAD inside a `0700` directory with a `0600` vault and `.state.enc.lock` advisory lock.
- **Schema (`schema_version = 1`):**
  - `store::decode_state` verifies `schema_version == 1` cleanly via a pre-check before hydrating full `State` (preventing spurious field errors on future schema bumps), while internal vault JSON structs avoid `deny_unknown_fields` so additive forward-compatible fields do not break older tools.
  - `config_toml` stores the administrator's exact commented TOML configuration string verbatim and is parsed into typed `Settings` on load (`#[serde(try_from)]`) with strict `#[serde(deny_unknown_fields)]` on TOML structs.
  - `subscription`, `users` (`BTreeMap<String, User>` with `created_at`, optional `note`, symmetrical `vless`, `hysteria2`, `amneziawg` including per-peer `preshared_key`, and `ssh_forwarding` credentials plus monotonic `next_uid`), and `servers` (symmetrical `roles` `vpn` / `subscription`, per-protocol `enabled` flags inside `vpn` for `vless`, `hysteria2`, `amneziawg`, and `ssh_forwarding`, `ports`, `arch`, `created_at`, optional `note`) stay managed via the CLI; public keys are omitted from JSON and derived deterministically from private keys (with OpenSSH key comments stripped).
- **Safe config editing & backups:** `kinveil config` decrypts **only** `config_toml` (never private keys, certs, or user lists) into RAM-backed `/dev/shm` tmpfs on Linux (`0700`/`0600`, zeroed on drop), validates TOML syntax and vault compatibility on save, and leaves comments/whitespace intact across all CLI operations. Every save rotates `<state_dir>/backups/<stem>.<rev>.enc` retaining the newest 20 revisions, and `kinveil restore` advances `revision` past both the existing vault and `backups/`.

## Host Isolation & Firewall (`table inet kinveil`)

- **First-install takeover guard:** On a fresh host (`/etc/kinveil/.managed` absent), `install.sh` requires `x86_64` Debian with systemd and aborts if `docker`, `podman`, `firewalld`, `netfilter-persistent`, `nginx`, `apache2`, `traefik`, `haproxy`, `x-ui`, `marzban`, active `caddy` on non-subscription nodes, active `ufw`, or non-default nftables tables (in `/etc/nftables.conf` or `nft list tables`) exist unless `--takeover` is passed. Original `/etc/nftables.conf` and `/etc/caddy/Caddyfile` files are saved once as `*.kinveil-orig` and restored on `kinveil server remove --wipe`; `/etc/nftables.conf` runs `flush ruleset` before loading `table inet kinveil` so stale `iptables-nft` kernel tables cannot interfere.
- **Verified binaries & SSH hardening:** `xray-linux-64` is verified against both the release zip digest (`XRAY_ZIP_SHA256`) and extracted/bundled `xray` ELF binary digest (`XRAY_BIN_SHA256`), unless overridden by an `[artifacts]` SHA-256 pair or `KINVEIL_XRAY_BIN`. `amneziawg-go` is verified against `[artifacts]` (`amneziawg_url` + `amneziawg_sha256`), `KINVEIL_AMNEZIAWG_BIN`, bundled/prebuilt release binaries (`AWG_PREBUILT_URL` + `AWG_PREBUILT_SHA256`), or a pinned upstream commit build (`AWG_COMMIT_SHA1`), and all cached/bundled/override binaries are checked for valid Linux `x86_64` ELF headers (`[artifacts]` overrides cache isolated by URL hash). OpenSSH calls run with `--`, `BatchMode=yes`, `StrictHostKeyChecking=yes` against a temp `0600` pinned `known_hosts` file, `ClearAllForwardings=yes`, `ForwardAgent=no`, `ForwardX11=no`, `PermitLocalCommand=no`, and sanitized loader environment variables (`LD_PRELOAD`/`LD_LIBRARY_PATH`).
- **Hardened systemd units:**
  - `kinveil-xray.service`: runs Xray-core as unprivileged system user `kinveil` (`nologin`) with `CAP_NET_BIND_SERVICE`, `0750`/`0640` TLS directory permissions, `ProtectSystem=strict`, `ProtectHome=yes`, and `PrivateDevices=yes`.
  - `kinveil-awg.service`: runs `amneziawg-go` on interface `kv0` with `RuntimeDirectory=amneziawg` (`0700`), `CAP_NET_ADMIN` + `CAP_NET_BIND_SERVICE`, and `ExecStartPost=/etc/kinveil/awg/apply-uapi.sh`.
  - `kinveil-ssh.service`: runs forwarding-only OpenSSH (`AllowUsers vpnssh*`, `AllowTcpForwarding local`, `ForceCommand /usr/sbin/nologin`) for per-user `vpnssh<uid>` accounts with `ProtectSystem=strict`, `ReadWritePaths=/run`, `ProtectHome=yes`, `PrivateTmp=yes`, `PrivateDevices=yes`, and `LockPersonality=yes`.
- **Content-addressed & DNS-ordered deploys:** Tar bundles stage only artifacts required by enabled protocols (`HAS_XRAY` / `HAS_AWG`), unpack into mode-`0700` `/run` staging directories, validate `/etc/nftables.conf` via `nft -c -f` before overwriting, and restart only services whose rendered files changed (`install_if_changed`, plus `systemctl restart caddy.service` when `Caddyfile` changes). Disabled roles/protocols stop/remove their units, secrets, and `vpnssh*` accounts cleanly. When supported by the host kernel, `install.sh` loads `tcp_bbr` and configures `fq` + `bbr` via `/etc/sysctl.d/91-kinveil-bbr.conf` (cleaned up on `--wipe`). Pure `vpn` / `ssh-forwarding` nodes converge first, Cloudflare DNS sync runs next, and the `subscription` host deploys last so ACME checks immediately match DNS.
- **Scoped nftables & unified egress isolation:**
  - `input` defaults to `drop` (permitting loopback, established/related, ICMP/ICMPv6, `admin_ssh.port`, and active role/protocol ports).
  - `forward` clamps TCP MSS to path MTU on `kv0` (`tcp option maxseg size set rt mtu`), blocks peer-to-peer routing across `kv0` (`iifname "kv0" oifname "kv0" reject`), rejects IPv6 on IPv4-only `kv0` (`meta nfproto ipv6 reject`), and always blocks `ALWAYS_BLOCKED_IPV4_CIDRS` (`0.0.0.0/8`, `100.100.100.200/32`, `127.0.0.0/8`, `169.254.0.0/16`, `224.0.0.0/4`, `240.0.0.0/4`)—expanding to full `PRIVATE_IPV4_CIDRS` (RFC1918 + CGNAT) when `block_private_networks = true`.
  - `/etc/kinveil/nft-egress.nft` enforces kernel-level `chain output` rules (`type filter hook output priority -10`) for **both** the unprivileged `kinveil` Xray UID and `@vpnssh_users`: allowing `ct direction reply accept`, `/etc/resolv.conf` DNS resolvers, and TCP `80,443` to co-located `subscription` host IPs (for Xray subscription self-refresh), then rejecting `fib daddr type local`, `::ffff:0:0/96`, `ALWAYS_BLOCKED_*` (or full `PRIVATE_*` when `block_private_networks = true`), stopping host-local / cloud IMDS SSRF even at the socket layer.
  - `/var/lib/kinveil/sub` uses mode `0710` (`root:caddy`) with `0640` files so `caddy` cannot list sibling subscription tokens.

## Protocol & Client Invariants

- **VLESS REALITY XHTTP (`src/state/defaults.rs`):** Supports independent toggling of `vless.stream` (`mode=stream-up`), `vless.packet` (`mode=packet-up`), and `hysteria2`. When only one VLESS mode is active, Xray's server inbound binds `"mode": "stream-up"` or `"packet-up"` explicitly (`"auto"` when both are active), with `padding_bytes: "100-1000"`, `sc_max_buffered_posts: 30`, and tuned `xmux` defaults (`maxConcurrency: "16-32"`, `hMaxRequestTimes: "600-900"`, `hMaxReusableSecs: "1800-3000"`). The Xray `freedom` outbound sets `"domainStrategy": "UseIP"` and blocks host public IPs + `ALWAYS_BLOCKED_*` (even with `[firewall] block_private_networks = false`), plus full RFC1918/CGNAT/ULA ranges when `block_private_networks = true`.
- **Hysteria2 + Throne SPKI pin:** Uses per-server Salamander PSK and self-signed IP-SAN ECDSA certificates. For Throne (`User-Agent` matching `^throne/` or `?ssh=1`), URIs emit `sni=<ipv4>`, `vcn=<ipv4>`, and literal unescaped `&insecure=0&tls_certificate_public_key_sha256=<b64-spki-sha256>`. Masquerade URLs and REALITY SNI/`target` validate against loopback/private/IMDS/`*.localhost` destinations, and REALITY SNI/`target` also reject `subscription.domain` and managed server IPs to prevent self-referential probing/routing.
- **AmneziaWG 3.1:** Allocates one `/32` per user inside `[amneziawg].subnet` (default `10.8.0.0/16`, `MTU = 1360`, IPv4 `dns_servers`), issues a per-user `PresharedKey` (`preshared_key=<hex>` in UAPI, `PresharedKey = <b64>` in INI), supports optional CPS `I2`..`I5` tags, and emits `random_trailers=true` / `disable_cookies=true` (`RandomTrailers = on` / `DisableCookies = on`). `net.ipv4.ip_forward` is enabled (`1`) only when AmneziaWG is active on that node.
- **Caddy subscription host:** Disables the Caddy admin API (`admin off`), binds `80/tcp` and `443/tcp` (`protocols h1 h2`, leaving `443/udp` free for Hysteria2), returns `404` on unknown tokens, routes Throne vs Happ variants, and emits `Profile-Update-Interval`, base64 `Profile-Title`, and optional `routing` headers.
